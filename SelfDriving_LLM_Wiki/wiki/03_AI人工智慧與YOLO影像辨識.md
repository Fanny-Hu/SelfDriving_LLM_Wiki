**# 第 3 章：AI 人工智慧與 YOLO 影像辨識**

------------------------------------------------------------------------

**## 1. 本章學習目標**

-   **掌握多任務全景駕駛感知架構**：理解車載視覺感知中的三項任務：目標偵測、可行駛區域分割與車道線分割。
-   **認識 YOLOP 論文架構**：了解共享 CSPDarknet
    特徵主幹、多尺度特徵融合，以及三個任務分支的設計。\[YOLOP.pdf，第
    1～8 頁（PDF 第 1～8 頁）\]
-   **理解多任務損失函數**：認識目標偵測、可行駛區域分割及車道線分割所使用的損失函數。
-   **了解模型效能與部署限制**：認識 YOLOP
    在不同硬體平台上的推論速度，以及多任務模型在實際道路應用時仍須面對的限制。

------------------------------------------------------------------------

**## 2. 章節簡介**

在自動駕駛的感知系統中，攝影機（Camera）可以取得道路影像中的物件、標線及場景資訊。車輛需要從影像中辨識交通物件、判斷可行駛區域，並找出車道線，才能將感知結果提供給後續的規劃與控制模組。

若不同感知任務分別使用獨立模型，可能增加車載運算資源的需求。為此，華中科技大學研究團隊提出
YOLOP（You Only Look Once for Panoptic Driving
Perception），利用共享特徵提取架構，同時處理目標偵測、可行駛區域分割及車道線分割三項任務。\[YOLOP.pdf，第
1～3 頁（PDF 第 1～3 頁）\]

本章將介紹 YOLOP
的主要網路架構、各任務的損失函數、論文評測結果，以及其在自動駕駛視覺感知系統中的應用方式。

------------------------------------------------------------------------

**## 3. 詳細技術小節**

**### 3.1 自動駕駛中的視覺感知核心任務**

YOLOP 將道路場景中的視覺感知分成三項主要任務。\[YOLOP.pdf，第 1～2
頁（PDF 第 1～2 頁）\]

1.  **交通目標偵測（Traffic Object Detection）**
    -   **輸出形式**：物件的二維邊界框（Bounding Box）、類別及信心分數。
    -   **辨識對象**：例如汽車、行人及自行車等交通場景中的物件。
    -   **應用說明**：偵測結果可提供給後續物件追蹤或碰撞風險評估模組使用；這些後續功能並不等於
        YOLOP 本身已完成完整追蹤或車輛控制。
2.  **可行駛區域分割（Drivable Area Segmentation）**
    -   **輸出形式**：影像中各像素所屬區域的分割結果。
    -   **辨識目的**：判斷影像中哪些區域屬於可行駛區域。
    -   **應用說明**：分割結果可作為後續路徑規劃的視覺參考，但不能單憑影像分割結果保證該區域在真實道路上絕對安全。
3.  **車道線分割（Lane Line Segmentation）**
    -   **輸出形式**：影像中的車道線像素分割結果。
    -   **辨識目的**：找出道路影像中的車道標線。
    -   **應用說明**：車道線資訊可提供給後續車道維持或車道規劃模組參考；實際控制仍需其他定位、決策與車輛控制系統配合。

------------------------------------------------------------------------

**### 3.2 YOLOP 網路架構**

YOLOP 使用共享特徵提取架構，讓模型在一次前向傳播（Forward
Pass）中，同時產生三項視覺感知任務的結果。論文架構包含特徵主幹、特徵融合部分及三個任務分支。\[YOLOP.pdf，第
2～3 頁（PDF 第 2～3 頁，圖 1）\]

``` mermaid
flowchart TD
    Input["行車圖像輸入（640×384×3）"] --> Backbone["共享特徵主幹（CSPDarknet）"]
    Backbone --> Neck["多尺度特徵融合部分（FPN + PAN）"]

    subgraph Heads["三種任務分支"]
        Neck --> DetHead["目標偵測分支（Detection Head）"]
        Neck --> DaHead["可行駛區域分割分支（Drivable Area Head）"]
        Neck --> LlHead["車道線分割分支（Lane Line Head）"]
    end

    DetHead --> Out1["物件邊界框、類別與信心分數"]
    DaHead --> Out2["可行駛區域像素分割結果"]
    LlHead --> Out3["車道線像素分割結果"]
```

**#### 3.2.1 共享特徵主幹（Shared Backbone）**

YOLOP 使用 CSPDarknet
作為共享特徵主幹。主幹網路負責從輸入影像中提取不同層次的特徵，再將特徵提供給後續的多任務分支。

共享主幹的設計可以避免三項任務完全各自使用一套獨立特徵提取網路，有助於減少重複運算。關於
CSP 結構的具體運算細節，應以論文架構圖及原文說明為準。\[YOLOP.pdf，第
2～3 頁（PDF 第 2～3 頁）\]

**#### 3.2.2 空間金字塔池化（SPP, Spatial Pyramid Pooling）**

空間金字塔池化是一種用來整合不同感受野資訊的特徵處理方式。YOLOP
架構圖中包含 SPP 模組，可協助模型取得不同範圍的場景特徵。

本章不列出特定池化核尺寸，避免加入目前未能由原始論文內容確認的數值。

**#### 3.2.3 特徵融合部分（Neck）**

YOLOP 的特徵融合部分結合 FPN（Feature Pyramid
Network，特徵金字塔網路）及 PAN（Path Aggregation
Network，路徑聚合網路）的設計概念。

-   **FPN**：透過不同層級特徵的融合，讓模型利用較高層的語意資訊。
-   **PAN**：進一步傳遞不同層級的特徵資訊，協助模型取得位置與細節資訊。

多尺度特徵融合可讓後續任務分支使用不同層級的影像特徵。\[YOLOP.pdf，第
2～3 頁（PDF 第 2～3 頁，圖 1）\]

**#### 3.2.4 三種任務分支（Task Heads）**

1.  **目標偵測分支**：輸出交通物件的邊界框、類別及信心分數。
2.  **可行駛區域分割分支**：輸出可行駛區域的像素級分割結果。論文架構中的上採樣使用最近鄰插值（Nearest-Neighbor
    Interpolation），不應誤寫為雙線性插值（Bilinear Interpolation）。
3.  **車道線分割分支**：輸出道路影像中的車道線像素分割結果。

------------------------------------------------------------------------

**### 3.3 多任務損失函數（Multi-task Loss Functions）**

多任務學習會讓同一個模型同時學習多項任務。訓練時，模型會依照各任務的損失計算結果更新網路參數。YOLOP
使用多任務損失設計，整合目標偵測、可行駛區域分割及車道線分割的學習目標。\[YOLOP.pdf，第
3～4 頁（PDF 第 3～4 頁，公式 1～4）\]

整體概念可表示為：

\[ `\mathcal{L}`{=tex}\_{total} =
`\alpha`{=tex}*1`\mathcal{L}`{=tex}*{det} +
`\alpha`{=tex}*2`\mathcal{L}`{=tex}*{da} +
`\alpha`{=tex}*3`\mathcal{L}`{=tex}*{ll} \]

其中：

-   (`\mathcal{L}`{=tex}\_{det})：目標偵測任務的損失。
-   (`\mathcal{L}`{=tex}\_{da})：可行駛區域分割任務的損失。
-   (`\mathcal{L}`{=tex}\_{ll})：車道線分割任務的損失。
-   (`\alpha`{=tex}\_1,`\alpha`{=tex}\_2,`\alpha`{=tex}\_3)：各任務損失的權重。

**#### 3.3.1 目標偵測損失（Detection Loss）**

目標偵測需要處理物件分類、物件存在性判斷及邊界框位置預測。YOLOP
的目標偵測損失包含分類、物件存在性及邊界框回歸等部分。

-   **Classification
    Loss（分類損失）**：衡量模型預測的物件類別與真實類別之間的差異。
-   **Objectness
    Loss（物件存在性損失）**：衡量模型對預測位置是否存在物件的判斷。
-   **Bounding Box
    Loss（邊界框回歸損失）**：衡量預測框與真實框的位置及形狀差異。論文使用
    CIoU（Complete Intersection over
    Union，完整交並比）作為邊界框回歸損失。

CIoU
會考慮預測框與真實框的重疊程度、中心點距離及長寬比等因素。其公式及符號定義應以
YOLOP.pdf 原文為準。\[YOLOP.pdf，第 3～4 頁（PDF 第 3～4 頁）\]

**#### 3.3.2 可行駛區域分割損失（Drivable Area Loss）**

可行駛區域分割任務需要讓模型判斷影像像素所屬的區域。模型會比較預測分割結果與資料集提供的真實標註，並根據兩者差異調整參數。

本節不自行推定路面與背景的像素比例，也不額外加入原始論文未明確支持的樣本分布數字。損失函數的實際組成以
YOLOP.pdf 所列公式為準。\[YOLOP.pdf，第 3～4 頁（PDF 第 3～4 頁）\]

**#### 3.3.3 車道線分割損失（Lane Line Loss）**

依據 YOLOP 論文，車道線分割損失由 Cross Entropy Loss（交叉熵損失）與 IoU
Loss（交並比損失）組成，而不是 Focal Loss 與 IoU Loss
的組合。\[YOLOP.pdf，第 3～4 頁（PDF 第 3～4 頁）\]

-   **Cross Entropy
    Loss（交叉熵損失）**：衡量模型對像素類別的預測與真實標籤之間的差異。
-   **IoU Loss（交並比損失）**：衡量預測區域與真實標註區域的重疊情況。

Focal Loss 不應在本節被描述為 YOLOP 車道線分割分支所使用的損失函數。

**### 3.4 模型訓練、評測與性能分析**

YOLOP 論文使用 BDD100K
資料集進行道路場景感知任務的評測。論文報告的主要結果如下。\[YOLOP.pdf，第
4～8 頁（PDF 第 4～8 頁，表 1～3）\]

  感知任務                          評測指標              YOLOP 論文報告結果
  --------------------------------- ------------------- --------------------
  目標偵測（Detection）             mAP50                              76.5%
  可行駛區域分割（Drivable Area）   mIoU                               91.5%
  車道線分割（Lane Line）           Accuracy                           70.5%
  車道線分割（Lane Line）           IoU                                0.262
  推論速度                          NVIDIA TITAN XP                   41 FPS
  推論速度                          NVIDIA Jetson TX2                 23 FPS

**結果解讀：**

YOLOP 的設計重點是使用單一模型同時處理三項道路視覺感知任務。論文報告其在
NVIDIA TITAN XP 平台上的推論速度為 41 FPS，並在 Jetson TX2 平台上報告 23
FPS。

比較不同模型時，必須確認使用相同資料集、評測指標及實驗設定。YOLOP
論文的目標偵測 mAP50 為 76.5%，而論文比較表中的 YOLOv5s 為
77.2%；因此不能宣稱 YOLOP 的目標偵測精度高於 YOLOv5s。YOLOP
的主要價值在於整合三項任務，而不是每一項單獨指標都必須優於其他模型。

**## 5. 重要原理與技術流程**

以下流程呈現 YOLOP
的多任務前向推論概念。訓練階段會依照各任務的損失計算結果更新模型參數；實際推論階段則輸出各任務的預測結果。

``` mermaid
flowchart TD
    A["輸入行車影像（640×384）"] --> B["CSPDarknet 共享特徵主幹"]
    B --> C["FPN + PAN 多尺度特徵融合"]
    C --> D["三種任務分支"]
    D --> E["目標偵測結果"]
    D --> F["可行駛區域分割結果"]
    D --> G["車道線分割結果"]
    E --> H["提供後續自動駕駛模組使用"]
    F --> H
    G --> H
```

訓練時，模型會根據三項任務的預測結果計算相應損失，並透過反向傳播（Backpropagation）更新網路參數。推論時則不需要執行損失計算及參數更新。

**## 6. 實際應用案例**

**### 6.1 自動駕駛視覺感知系統的應用延伸**

YOLOP
能在單一模型中同時輸出目標偵測、可行駛區域分割及車道線分割結果。這些資訊可以作為自動駕駛或先進駕駛輔助系統的視覺感知輸入。

在實際系統中，其他模組可以進一步利用這些結果進行物件追蹤、碰撞風險評估、車道維持及路徑規劃。

**資料層級說明：**上述內容屬於根據 YOLOP
輸出功能所做的工程應用延伸，不代表 YOLOP
原始論文已完成上述所有車輛控制功能的實車實驗。ONNX、TensorRT、INT8
量化及特定車規晶片部署，也不應在沒有額外來源的情況下寫成 YOLOP
論文的實驗成果。

**技術限制補充：**

YOLOP
主要依賴攝影機影像進行視覺感知。當影像受到夜間低照度、雨霧、逆光、鏡頭污損或道路標線不清楚等因素影響時，模型辨識結果可能受到干擾。實際自動駕駛系統通常還需要結合其他感測器、定位、規劃及車輛控制模組，不能只依賴單一視覺模型。

**## 10. 本章重點整理**

1.  自動駕駛視覺感知的重要任務包含目標偵測、可行駛區域分割及車道線分割。
2.  YOLOP 使用共享特徵提取架構，在單一模型中整合三項道路視覺感知任務。
3.  YOLOP
    的目標偵測分支使用分類、物件存在性及邊界框回歸等損失；車道線分割損失則由
    Cross Entropy Loss 與 IoU Loss 組成。
4.  YOLOP 論文報告在 NVIDIA TITAN XP 平台上達到 41 FPS，在 Jetson TX2
    平台上達到 23 FPS。
5.  YOLOP
    的輸出可提供後續自動駕駛模組參考，但完整自動駕駛仍需要感測器融合、定位、路徑規劃、決策及車輛控制等系統共同運作。
