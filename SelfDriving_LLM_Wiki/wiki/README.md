
**# 自動駕駛技術知識百科 (Autonomous Driving Tech Wiki)**

歡迎來到**自動駕駛技術知識百科**！本知識庫專門為自駕車與先進駕駛輔助系統（ADAS）的學習者、研發工程師與技術愛好者打造，主要依據 `AGENTS.md` 規範與 `raw/` 資料夾中收錄的 8 份原始文獻、政府研究報告及產業技術資料進行系統化整理。內容以提供的原始資料為主要依據；原始文獻未涵蓋的通用工程知識或延伸議題，會另外標示，避免將補充說明誤認為原始資料的研究結果。

**## 核心資料來源（Single Source of Truth）**

本知識庫以專案 `raw/` 資料夾中的 8 份原始檔案作為主要資料依據，依資料性質分為以下四類。各類別代表資料型態與用途，不表示所有文件都具有相同的學術審查或法規效力：

1. **A. 學術論文與學位論文**：

   - `感測器融合.pdf`（國立成功大學碩士學位論文《結合光達相機與雷達之追蹤演算法發展及其於自駕車之應用》，2019）

2. **B. 政府研究報告（自動駕駛分級、道路測試與法規研議）**：

3. **C. 產業技術專文（工程實務經驗）**：
   - `自駕車應用圖資選擇最佳行駛路徑.pdf`（財團法人車輛研究測試中心 ARTC 技術專文，2022）

4. **D. 技術推廣簡報與簡介（概覽性資料）**：
   - `自動緊急煞車性能評估.pdf`（財團法人車輛研究測試中心 ARTC 技術資料，2024）
